# Sintunado Ngani!! app

Home party videoke. This is the Android app for the TV and for phones. It opens the website https://sintunado-ngani.web.app, so the app itself rarely needs updating.

## Download

**[Download the app (APK)](https://github.com/CptnZer0/sintunado-ngani-app/releases/latest/download/sintunado-ngani.apk)**

## Install on an Android phone

1. Open the download link above on the phone.
2. If Chrome warns about the file type, tap **Download anyway**.
3. Open the downloaded file. When Android asks, allow Chrome to install unknown apps (one time).
4. If Play Protect warns, tap **Install anyway**.

On a phone, the app opens the phone remote. Back closes a menu first. With nothing open, press Back twice to leave.

## Install on an Android TV

1. Copy the APK to a USB flash drive and plug it into the TV.
2. On the TV, open **Settings > Device Preferences > Security & restrictions > Unknown sources**, and allow your file manager (for example "File Commander").
3. Open the APK in the file manager and install it. It installs over an older version.

On a TV, the app opens the Party board: the QR code, the room number and the reserve list.

## No Android?

Open https://sintunado-ngani.web.app in any browser. On an iPhone, tap Safari's Share button, then **Add to Home Screen**.
